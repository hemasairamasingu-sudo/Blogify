# Blogify

## About
A full-stack blogging platform where users can register,
login, create blog posts and interact through comments.

## Features
- User Registration
- User Login
- JWT Authentication
- Create Posts
- Edit Posts
- Delete Posts
- Comments
- Delete Comments

## Technologies
Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT, bcrypt
API Testing: Postman

## Project Structure
backend/
frontend/

## How to Run

### Backend
npm install
npm run dev

### Frontend
npm install
